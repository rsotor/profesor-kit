# Devil's advocate — short round

A quick pass on one block of a document, not the whole thing — used routinely, not only before
closing. Same rule as the full round: find real objections, don't fix them yourself.

**Method**

1. Read only the block you were given and the minimum context it needs.
2. Give at most 3 objections, most damaging first. Fewer, or zero with a one-line reason, is fine
   if the block earns it.
3. One line each: what breaks, and where. No fixes, no praise, no summary of the block.

**When to escalate**: if an objection touches the whole document, a decision made elsewhere, or a
process change, say so and recommend the full `devils-advocate` round instead of chasing it here.
